Inchecken bij een les

Lessen waar je nu kunt inchecken

  • Biologie · 10.303e uur, lokaal 2.10, Anouk SmitOpen
Je bent ingechecktJe staat bij Biologie, 3e uur, nu op aanwezig. Je docent ziet het meteen in de presentielijst.

Lukt het niet?

  • De code op het bord verandert elke 30 seconden. Typ de code die je nu ziet, een foto van eerder werkt niet.
  • Inchecken kan alleen bij lessen van je eigen groep, zolang de inchecktijd open is.
  • Check je in na de start van de les plus de marge van je docent, dan sta je op te laat.
  • Heeft je docent je al op de lijst gezet, dan verandert inchecken niets. Klopt het niet? Zeg het tegen je docent.
