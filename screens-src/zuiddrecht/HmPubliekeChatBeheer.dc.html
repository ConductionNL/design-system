Kanaal Website

Aangemaakt door Anouk Bakker op 2 oktober · laatst gewijzigd vandaag 09:40
Alleen agents zonder tools, geheugen of bestanden. Een agent met tools wordt bij opslaan geweigerd.
Eén website per regel. Andere websites krijgen geen antwoord van dit kanaal.
Alleen wat OpenRegister zonder inloggen toont.
Daarna antwoordt het kanaal tot middernacht niet meer.
Staat boven het gesprek, vóór de eerste vraag.

Op de website zetten

Plak één van beide in de website. De knop verschijnt rechtsonder op elke pagina.
Script
<script src="https://cloud.zuiddrecht.nl/apps/hermiq/public/chat.js"
  data-channel="website-7f3a" defer></script>
