OpenProject screens.

OpenProject and Nextcloud in one shell. One set of tokens drives both, so you see no difference when you move from one to the other. These screens draw OpenProject to the Nextcloud canon: the same top bar, the same navigation, the same buttons. The mail, calendar and tasks that link to work packages sit with the other screens. Open a screen and step through them with the arrow keys.
