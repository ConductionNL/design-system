Code
export default async function beforeSave(record, ctx) {
  if (!record.postcode) {
    record.postcode = await ctx.lookup('bag', record.adres).postcode;
  }
  if (record.prioriteit === 'hoog' && !record.toelichting) {
    return ctx.refuse('Een hoge prioriteit vraagt een toelichting.');
  }
  return record;
}
Draait in een sandbox buiten Nextcloud, zonder netwerk behalve de opzoekingen die ctx aanbiedt. Geeft het record terug, gewijzigd of niet, of weigert met een reden.

Zo ziet de gebruiker een weigering

Niet opgeslagen. Een hoge prioriteit vraagt een toelichting. (hook Postcode aanvullen en prioriteit controleren)
De weigering staat ook in het logboek van de hook en in de audit trail van het record, met de versie van de code.
