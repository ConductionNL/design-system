## ADDED Requirements

### Requirement: The `ai` frontmatter key is opt-in and never defaulted

The system SHALL treat the `ai` frontmatter key as strictly opt-in. A docs or blog page MAY declare it, and its permitted values SHALL be exactly `generated`, `modified` and `assisted`, mapping to the three official EU marks.

A page that does NOT declare `ai` SHALL render no disclosure whatsoever. The system SHALL NOT provide a site-wide default, SHALL NOT inherit a value from a parent directory, sidebar or plugin option, and SHALL NOT infer a value from page content.

This is a correctness requirement, not a preference. Labelling a human-authored page as AI-generated publishes a false statement about authorship, which is the harm the disclosure regime exists to prevent.

#### Scenario: Page declares a disclosure

- **WHEN** a page's frontmatter contains `ai: generated`
- **THEN** the page SHALL render the disclosure banner using the Fully AI-Generated mark

#### Scenario: Page omits the key

- **WHEN** a page's frontmatter contains no `ai` key
- **THEN** the page SHALL render no disclosure banner and no icon

#### Scenario: No site-wide default exists

- **WHEN** the preset is configured with no per-page `ai` keys anywhere
- **THEN** no page SHALL render a disclosure banner, and the preset SHALL expose no option that would enable one globally

### Requirement: An unrecognised value fails loudly and renders nothing

An `ai` value outside the permitted set SHALL raise a build-time warning that names the offending file, the offending value, and the three permitted values. The page SHALL render no banner.

The system SHALL NOT fall back to any mark when the value is unrecognised. A typo such as `ai: genrated` must not become a published claim.

#### Scenario: Misspelled value

- **WHEN** a page declares `ai: genrated`
- **THEN** the build SHALL emit a warning naming the file, the value `genrated`, and the permitted values `generated`, `modified`, `assisted`
- **AND** the page SHALL render no disclosure banner

#### Scenario: Empty value

- **WHEN** a page declares `ai:` with an empty value
- **THEN** the build SHALL emit the same warning and the page SHALL render no disclosure banner

### Requirement: Each value renders its corresponding official EU mark

The three permitted values SHALL map to the Commission's marks as follows: `generated` to Fully AI-Generated, `modified` to Partially AI-Modified, `assisted` to Basic.

The marks SHALL be served from the icons vendored in the preset. The component SHALL NOT fetch them over the network at build or run time; `ec.europa.eu` is not on the pipeline's egress allowlist, so a fetch would fail closed in CI.

Each mark has its own aspect ratio — Basic is square (`566.93 × 566.93`), Partially AI-Modified is `1700.79 × 566.93`, Fully AI-Generated is `1789.84 × 566.93`. Rendering SHALL preserve the source aspect ratio; the marks SHALL NOT be stretched or cropped to a uniform box.

#### Scenario: Generated maps to the correct mark

- **WHEN** a page declares `ai: generated`
- **THEN** the rendered banner SHALL reference an `ai-generated-*` vendored asset

#### Scenario: Assisted maps to the basic mark

- **WHEN** a page declares `ai: assisted`
- **THEN** the rendered banner SHALL reference an `ai-*` vendored asset that is neither `ai-generated-*` nor `ai-modified-*`

#### Scenario: Aspect ratio is preserved

- **WHEN** any of the three marks is rendered
- **THEN** its rendered width-to-height ratio SHALL match its source `viewBox` ratio within a 1% tolerance

### Requirement: Colour treatment follows the active theme

The Commission ships each mark in four colour treatments (`black`, `white`, `black transparent`, `white transparent`) so it stays legible on any background. The component SHALL select a treatment appropriate to the active Docusaurus colour mode, using a dark-ink treatment in light mode and a light-ink treatment in dark mode.

Switching colour mode SHALL update the rendered mark without a page reload.

#### Scenario: Light mode

- **WHEN** the site is in light colour mode and a disclosure renders
- **THEN** the mark SHALL use a black treatment

#### Scenario: Dark mode

- **WHEN** the site is in dark colour mode and a disclosure renders
- **THEN** the mark SHALL use a white treatment

#### Scenario: Live toggle

- **WHEN** a reader toggles colour mode while a disclosure is on screen
- **THEN** the rendered mark SHALL change treatment without a page reload

### Requirement: Copy is localised across the preset's four locales

The disclosure copy SHALL be available in the preset's four locales — `nl` (default), `en`, `de` and `fr` — and SHALL render in the page's active locale.

Each of the three values SHALL have distinct copy: a page generated by AI, a page partially modified with AI, and a page written with AI assistance are three different statements and SHALL NOT share one string.

#### Scenario: Dutch default

- **WHEN** a page declares `ai: generated` and the active locale is `nl`
- **THEN** the banner copy SHALL render in Dutch

#### Scenario: Locale coverage

- **WHEN** the disclosure renders in any of `nl`, `en`, `de`, `fr`
- **THEN** copy SHALL exist for that locale for all three values, with no untranslated fallback string

### Requirement: Copy states a fact and claims no compliance

The disclosure copy SHALL state what was done to the page. It SHALL NOT assert that the page, the site or the organisation is compliant with the EU AI Act, and SHALL NOT state or imply adherence to the Code of Practice on Transparency of AI-Generated Content.

The Commission is explicit that use of the icons is optional, that it does not establish legal compliance on its own, and that non-signatories should not signal adherence to the Code through them. Copy asserting compliance would therefore be both untrue and the specific misuse the Commission warns against.

#### Scenario: Copy makes no compliance claim

- **WHEN** the disclosure renders in any locale for any of the three values
- **THEN** the copy SHALL NOT contain a compliance assertion such as "compliant with", "conform", "voldoet aan" or "in accordance with the AI Act"

#### Scenario: Copy makes no Code-of-Practice claim

- **WHEN** the disclosure renders in any locale
- **THEN** the copy SHALL NOT state or imply that Conduction adheres to, or is a signatory of, the Code of Practice

### Requirement: The component is exported for inline MDX use

The preset SHALL export the disclosure as a component usable directly in MDX, so an author can place a mark somewhere other than the page top — for example beside a single AI-generated figure within an otherwise human-written page.

Used inline the component SHALL take the disclosure kind as a prop, and SHALL render identically to the frontmatter-driven banner for the same kind.

#### Scenario: Inline use

- **WHEN** an MDX page contains the disclosure component with a kind of `modified`
- **THEN** it SHALL render the Partially AI-Modified mark with the same copy the frontmatter-driven banner would use for `modified`

#### Scenario: Inline use does not require frontmatter

- **WHEN** a page uses the component inline but declares no `ai` frontmatter key
- **THEN** the inline disclosure SHALL render and no page-top banner SHALL be added
