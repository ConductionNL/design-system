How this mapping is made, and how to correct it

A script reads every drawn screen and recognises the canon patterns in it. A table with toolbar and pagination becomes CnDataTable with CnActionsBar. Folder tabs under a header become CnDetailPage. KPI tiles become CnDashTileWidget on CnDashboardGrid. Citizen and school pages map to the portaliq site widgets.

Some things a pattern rule cannot see. Those are set per screen in an override file. Wrong or missing a component on a screen? Correct it there and run the script again.

  • Corrections per screen: screens-src/components-overrides.json
  • Catalogue and pattern rules: scripts/screens/components.py
  • Output: preview/screens/components.json
