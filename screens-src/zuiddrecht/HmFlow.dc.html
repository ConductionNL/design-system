Stappanelen van de nieuwe stappen

Elke stap uit het palet heeft zijn eigen paneel. Hieronder de code-stap, een andere flow starten, een n8n-workflow starten en een agent op een andere server.

Agent op andere server

Een beheerder registreert de agent via een bron in integriq. De kaart toont zijn skills; een taak gaat heen en komt met zijn antwoord terug.
