Feature#58412· created by Olivia Brandt on 5 Oct, updated 2 days ago

Link Nextcloud project folders on rollout

Description

When a project goes live for Ville de Lyon, every work package needs a folder in Nextcloud without someone creating it by hand. The folder is made from the project template, named after the id and subject of the work package, and shared with the project members. People in Lyon work in Files and in OpenProject at the same time, so the link has to survive a rename on either side (the failing case is #58102).

Scope for 16.5

  • Create the folder from the project template when a work package is created
  • Share the folder with the members of the project, read and write
  • Keep the link when the folder is renamed in Nextcloud
  • Keep the link when the subject of the work package changes
  • Show the folder in the Files tab with its file count and size

Out of scope: moving the phase 1 folders that Lyon still keeps on their own server. That waits for the mail archive question in the thread with Marc Dubois. The rollout itself is planned for 2 November, so this work package must be in review by the Lyon review on Thursday 15 October.
