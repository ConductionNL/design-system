Needs a new token or option
  • Text colour of the active menu itemToday it takes the primary text colour, which fails on a tint.
  • Badge colour in the menu onlyThe badge token is global; the red badge should be menu-scoped.
  • Card shadowCn cards read --color-box-shadow; thematiq has no token for it.
  • Light tints per statusthematiq does not set --color-*-light yet.
  • Content surfaceWhether #app-content is white or transparent needs its own token.
  • Brand stripeA CSS option like the environment marker: three colours and their ratio.
More theme options worth adding
  • A "workplace layout" switchLight or coloured header, white or tinted menu, as one option per theme. Today only hide_slogan, show_menu_labels and icon_pack exist.
  • DensityComfortable or compact rows and cards.
