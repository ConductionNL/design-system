Page header, toolbar and filters

Every page opens the same way: the title on top, under it a subtitle on an index page or the breadcrumb on a detail page, and the buttons to the right of the title. An index adds one toolbar: saved views on the left, the filter and the view switch on the right.

  1. 1Title. The page or the object, 28 px bold, first in reading order. A detail page puts its type and status pills above it.
  2. 2Subtitle or breadcrumb. An index says what is shown against the whole: "Showing 8 of 46". A detail page shows the way back: list, then the object number.
  3. 3Two rows. Row 1 holds the title with the buttons to its right, row 2 the subtitle line over the full width, so a long subtitle runs on under the buttons. The primary action is the rightmost button, filled blue.
  4. 4Download. On every index. It exports what the list shows now, with the active filters, as a spreadsheet or CSV.
  5. 5buildiq. The orange square opens the page definition in buildiq. Icon-only, so it never competes with the real work.
  6. 6More. Everything rare. A detail page keeps its daily actions out here (Edit, the quick actions) and folds the rest in.

Four ways to look at the same list

  • Table. The default. Dense, one row per item, every column sortable, the row opens the detail page.
  • Cards. For things with a face or a picture: residents, products, publications. Avatar or image first, two lines of text, the status pill.
  • Board. Columns per value of one object property, the status by default; the items as cards. The same filters apply; dragging a card changes the property. A sales pipeline is the same board on the stage property.
  • Map. Only when the objects carry an address. Pins on the map, the filtered list beside it; the switch hides the option otherwise. In this canvas the map is drawn on the dossiq case list, because cases carry addresses and reports in pipelinq become cases.

Rules

  • 1The subtitle counts: "Showing 8 of 46". Never a bare total when the list shows fewer. The table footer repeats "8 of 46" on the left and numbered pages on the right (1 2 3, Next); there is no "Show more".
  • 2Saved views are the quick way in: a view is a filter set with a name and a live count. "Save as a view" in the panel makes one.
  • 3The Filter button carries the number of active filters. Open, it expands under the toolbar; it never covers the list. The search field always sits under the toolbar, with the active filter chips beside it.
  • 4Active filters stay visible as chips with a remove button, plus Clear all. Removing a chip updates the list at once.
  • 5Few options are checkbox chips; many options are a select; dates are two date fields. A toggle is a single checkbox.
  • 6Download exports the list as it is shown: same view, same filters, same sort. Column choice is in the table header menu.
  • 7Every row starts with a checkbox and ends with one "..." menu: no icons on hover, no text buttons in a row. The blue selection band appears above the table only while rows are selected.
  • 8At phone width the buttons wrap under the title, the toolbar stacks, the table scrolls sideways and Cards becomes the better default.
