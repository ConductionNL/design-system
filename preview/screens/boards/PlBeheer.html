Het label Bewoners staat op 23 taken in 4 projecten. Verwijderen haalt het van al die taken af, ook van taken die u zelf niet kunt zien. Dit kan niet ongedaan worden gemaakt.

Codeforges

Koppel taken aan commits, pull requests en merge requests.

GitHubGekoppeld via Integriq
Commits en pull requests komen bij de taak als de taaksleutel, zoals MARKT-142, in het commitbericht, de branchnaam of de titel staat. Integriq ontvangt de gebeurtenissen; Planninq belt GitHub zelf nooit.
Webhookadres voor GitHubhttps://cloud.zuiddrecht.nl/apps/integriq/api/endpoints/github-planninq
GitLab gemeentegit.zuiddrecht.nlAlleen links
Projectleden plakken een link naar een commit of merge request op de taakpagina; Planninq herkent GitLab-adressen en toont ze bij Code. Automatisch koppelen gaat nu alleen voor GitHub.
Zonder Integriq kunnen projectleden nog steeds een link op de taak plakken.
